# Elie-Andre Disso — portfolio

Personal portfolio: selected AI projects, research, writing and a downloadable public CV.

Built with static HTML, CSS, JavaScript and SVG. No framework, package installation or build step is required. Motion respects reduced-motion preferences and touch input.

## Files

- `index.html`: portfolio homepage.
- `cv.html`: fuller public CV.
- `content.js`: reviewed project descriptions and Medium article links.
- `script.js`: filters, project notes and interactions.
- `style.css`: desktop, mobile and print styles.
- `assets/`: portrait and favicon.
- `output/pdf/Elie-Andre-Disso-Public-CV.pdf`: public CV download.

## GitHub Pages

Publish from the `main` branch and the repository root. `.nojekyll` keeps the site as plain static files. Relative URLs support both account sites and project sites.

For local preview, serve this directory with any static web server.

Only reviewed public files belong in this repository. Do not add personal documents, credentials, client records or private project source code. Private projects are described only through approved public overviews.
